## 8. Структурные проблемы CSV

- **Смещение колонок** у записей с пустым `rating`: CSV парсер считывает `reviews_count` как рейтинг, `site` — как отзывы, `phone` — как сайт.
- **2 пустые строки** в конце файла (строки 207–208).
- **Кавычки в имени**: `c_001145` — `ООО ""Ромашка""` (двойные кавычки внутри поля).
- **Запятые в адресах** — экранированы кавычками, ок.

## Рекомендации

1. **Не загружать CSV как есть** — нужен отдельный ETL с валидацией и исправлением.
2. **Города:** нормализовать через словарь (маппинг битых/английских → правильных).
3. **Рейтинги:** отбросить `< 0` и `> 5`, `N/A` → NULL, `"4,5"` → `4.5`.
4. **Отзывы:** отрицательные → 0, дробные → округлить, `много` → NULL или 1000.
5. **Сайты:** `https://,` → NULL, `htp://` → `http://`, `нет сайта` → NULL.
6. **Телефоны:** валидация по маске `+7 (XXX) XXX-XX-XX`.
7. **Дедуп:** внутри CSV оставить последнюю версию; с JSON — решить бизнес-правилом (кто приоритетнее).
8. **Смещённые колонки:** детектировать по паттерну (rating пустое, reviews_count 1–5) и сдвигать назад.
